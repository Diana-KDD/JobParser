# Парсинг и анализ вакансий с сайта https://startup.jobs/

## Стек технологий

- Платформа: Node.js
- СУБД: PostgreSQL

## Реализовано

- Получение стран по API
- Добавление стран в бд
- Получение ролей по API
- Добавление ролей в бд

## БД

- dates_latest_updates - таблица для отслеживания последних обновлений "словарей"

  | Колонка    | Тип               |
  | ---------- | ----------------- |
  | id         | TEXT, PRIMARY KEY |
  | name_table | TEXT, UNIQUE      |
  | date       | DATE              |

- countries - таблица - "словарь" для хранения стран

  | Колонка      | Тип                      |
  | ------------ | ------------------------ |
  | country_code | varchar(15), PRIMARY KEY |
  | name         | TEXT                     |

- roles - таблица - "словарь" для хранения ролей
  | Колонка     | Тип               |
  | ----------- | ----------------- |
  | id          | TEXT, PRIMARY KEY |
  | title       | TEXT              |
  | slug        | TEXT, UNIQUE      |
  | parent_slug | TEXT, NULL        |

config/db - реализовано подключение к бд
config/init - создание необходимых таблиц в бд

repositories/... - содержит методы для работы с таблицами в бд.

Services/... - логика

parsing - содержит методы для отправки запроса и получения ответа

app - главный файл запуска
